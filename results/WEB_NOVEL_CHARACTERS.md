**Where each name came from**

- **Repo-labelled**: the repo's own hand-checked web novel characters, recounted from the raw data.
- **Extended search**: well-known web novel characters (Reverend Insanity, Lord of the Mysteries, Worm, Shadow Slave, ORV, Mother of Learning, Unsong, HPMOR, Kingdom's Bloodline, popular Chinese, Korean and Western web novels) searched by name, plus names the repo had tagged to a web novel but never classified.
- **Discovered**: Chinese-looking (pinyin) names from the repo's 18,394 unclassified names. Their work is inferred from which web novel title is mentioned in the same post or comment, so treat it as a best guess. A "Worm" co-mention next to a Chinese name almost always means "Gu worm" (Reverend Insanity), so it is counted as Reverend Insanity.

Single-word names (Adam, Amon, Cassie, Hermes...) are matched only when capitalised and can still pick up unrelated uses; they are flagged.
